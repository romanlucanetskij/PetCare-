# PetCare+

PetCare+ — демонстраційна веб-платформа ветеринарної клініки, реалізована на ASP.NET Core MVC з API на базі JWT-аутентифікації. Інтерфейс повністю україномовний і містить окремі кабінети для клієнтів, ветеринарів та адміністратора.

## Можливості

- 🔐 Реєстрація та вхід через JWT з ролями `client`, `vet`, `admin`.
- 🐾 Управління улюбленцями клієнта (створення, редагування, видалення, перегляд).
- 📅 Запис на прийом до ветеринара з контролем статусу, діагнозу та нотаток.
- 🩺 Кабінети користувачів з відповідними даними та формами.
- 📊 Адмін-панель із базовою статистикою та керуванням списком ветеринарів.

## Стек

- ASP.NET Core 7 (MVC + Web API)
- Entity Framework Core (SQLite)
- JWT Bearer Authentication
- BCrypt.Net для хешування паролів

## Підготовка середовища

1. Встановіть [.NET 7 SDK](https://dotnet.microsoft.com/en-us/download).
2. Клонування репозиторію та перехід у каталог:
   ```bash
   git clone <repo-url>
   cd PetCare-
   ```
3. Відновіть пакети та застосуйте міграції (база створюється автоматично під час запуску):
   ```bash
   dotnet restore
   dotnet run --project src/PetCarePlus/PetCarePlus.csproj
   ```

За замовчуванням застосунок використовує SQLite-файл `petcareplus.db` у каталозі проєкту. Після першого запуску створюється адміністратор з логіном `admin@petcareplus.ua` та паролем `Admin123!`.

## Основні ендпоїнти API

- `POST /api/auth/register` — реєстрація клієнта або ветеринара.
- `POST /api/auth/login` — отримання JWT токена.
- `GET /api/pets` — перелік улюбленців поточного користувача.
- `POST /api/pets` — створення улюбленця (клієнт).
- `PUT /api/pets/{id}` / `DELETE /api/pets/{id}` — оновлення та видалення улюбленця.
- `GET /api/appointments` — записи користувача залежно від ролі.
- `POST /api/appointments` — створення запису на прийом (клієнт).
- `PATCH /api/appointments/{id}` — оновлення статусу, діагнозу або нотаток (ветеринар/адмін).
- `DELETE /api/appointments/{id}` — скасування запису (клієнт, вет, адмін).
- `GET /api/admin/vets` — список ветеринарів (адмін).
- `POST /api/admin/vets` — підвищення користувача до ролі ветеринара (адмін).
- `GET /api/admin/stats` — ключова статистика клініки (адмін).
